AI Evaluation & Scoring Agent

The problem

Reviewing a steady stream of new listings by hand took time, and it was hard to apply the same criteria to every one.

What I built

A fully automated AI agent that runs every weekday: it pulls in new listings, scores each against a custom rubric I designed, and writes a short rationale for every recommendation. It started as a daily digest; I evolved it into a weekly summary email and monthly recap, with a health check that flags if the data feed breaks.

How it works

  1. Collects new listings automatically every weekday
  2. Scores each one against a custom rubric and explains the score
  3. Delivers a ranked weekly summary and a monthly recap by email

Result

Manual review became a ranked, decision-ready shortlist delivered every week, with the reasoning visible so each recommendation can be checked. In its first two months, it scored 159 listings and narrowed them to 65 worth pursuing.

AI Documentation Search Agent

The problem

Information spread across a growing collection of documents and notes is slow to search. Finding the right answer means opening files one by one or relying on memory.

What I built

An AI agent that answers plain-language questions from a collection of documents. Every answer quotes its sources down to the exact lines, and every citation is automatically checked against the documents before it's shown.

How it works

  1. Takes a plain-language question
  2. Searches and reads the documents the way a person would, trying new terms when a search comes up empty
  3. Returns an answer with cited quotes, each verified against the source

Result

Answers in seconds instead of digging through files. In testing, it handled all 9 questions with verified citations, including trick questions, topics the documents don't cover, and documents that contradict each other.

Built with

  • Claude Code
  • Claude API
  • Python

AI Product Research & Evaluation Pipeline

The problem

Comparing products consistently takes a lot of research, and results vary depending on who does it and what they focus on.

What I built

A multi-step AI pipeline that researches each product from source links, evaluates it against custom criteria, and writes it up in a standardized format I designed. A separate audit stage then fact-checks every claim against the sources, and finished evaluations are filed automatically to Google Drive.

How it works

  1. Reads the product list from a shared Google Doc and researches each product against custom criteria
  2. Writes a standardized evaluation: score, pros and cons, and verdict
  3. Fact-checks every claim against the sources, then files it to Google Drive

Result

Completed 40 consumer electronics evaluations across 8 categories in one consistent format. The audit stage checked 792 individual claims and flagged 73 that the sources didn't support.

Built with

  • Claude Code
  • Claude API
  • Python
  • Google Drive API
